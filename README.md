# bigbite

Cinematic scroll-driven food truck interactive web experience for **BIG BITE — Big Flavour. Bigger Cravings.**

## Features
- **36-Frame Cinematic Sequence:** Powered by HTML5 Canvas and synchronized frame-by-frame with GSAP ScrollTrigger.
- **GSAP Hardware Pinning:** Fixed hero viewport with smooth scrub through arrival, stopping, zoom-in, window opening, and chef wok action.
- **Lenis Smooth Scrolling:** Buttery-smooth wheel and touch scrolling.
- **Interactive Story & Menu:** Editorial design, 4 signature menu cards with full menu modal, cooking story, mobile truck schedule, and responsive navbar.

## Getting Started
```bash
npm install
npm run dev
```
